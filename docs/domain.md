# 控制关系不确定时海鲜市场集中度资料约定

份额的交易分母限所选边界内的已登记成交。多数表决权是控制证据的一类，不代表少数经济权益自动获得控制；joint_agreement 说明共享决策协议，不能任意归到其中一个家族。联合经营是待分析的假设，不改变历史工商证据。时间有效期均为左闭右开，valid_to 为空表示尚无已知终止日。份额集中度是统计量，不是法律裁定。

## 文件和数值语义

空单元格只在带问号的类型中表示缺失；零和空值不同。金额由十进制定点字符串保存，浮点数仅用于探索性统计。所有数据均为本地生成的虚构经营记录，不对应真实公司、客户或住址。数值剖面只反映观察数据，不能代替总体推断。

研究备注的参数为业务自由对象，不代表已执行了任何统计模型。原始表与已有视图可单独查询。

## 集中度研究口径

### 证据分级与经营主体

控制证据不是同质的连通关系，分组时按以下顺序区分：

1. **生效期过滤**：所有边必须满足 `valid_from <= as_of < valid_to`，左闭右开；到期边进入 `excluded_edges`，调整 `as_of` 才可能重新生效。
2. **权利类型**：`voting` 为表决权控制证据，可沿链条传递，分组结果保留每条边组成的 `control_path_edge_ids`；`equity` 只是经济权益，任何假设下都不合并主体；`joint` 必须结合同一 `joint_agreement` 理解。
3. **确认状态**：`unconfirmed` 边是待核证据，基线分组不采用，只有显式 `include_unconfirmed=true` 时才纳入。
4. **共同控制策略**：基线 `independent` 把协议各方保持独立，`joint_group` 才按协议显式合并；两种结果都展示，不唯一认定归属。
5. **交叉持股**：双向 `equity` 边被标记为 `cross_holdings`，仅提示关联，不产生控制连通。

每个登记主体在任一分组中恰好出现一次；投资型主体本身没有成交时仍保留在组内，份额贡献为零。

### 市场边界与分母

边界由期间、品类（`species`）、鲜冻形态（`forms`）和地区（`regions`）共同定义。`period` 用 `YYYY-MM` 简写，也可用 `period_from`/`period_to` 给出闭区间日期。份额分母始终是边界内**已登记成交合计**，金额与重量分别计算。覆盖声明为 `unknown` 或无声明时不存在外部交易基准，响应中 `is_whole_market` 恒为假，不得把登记分母表述为全市场总额；边界变化时 `coverage` 同步交代适用的覆盖声明、观察额与已知额之比。

### 集中度与情景区间

CR1、CR4 为前一或前四大经营主体份额之和，HHI 为份额百分数的平方和（以点表示）。金额与重量口径分开输出，因为活鲜与冻品的重量含义不同。对不能唯一认定的关系，服务在四个显式假设（未确认边纳入与否 × 共同控制两种策略）下分别分组计算，返回每个指标的取值区间及取得极值的假设，并列出改变分组的具体边 ID，而不是给单一精确答案。

### 联合经营假设

`joint_operation` 是工作人员显式给出的假设：把若干登记实体所在的基线经营主体试算为一个联合主体。输出合并前后的 CR、HHI 及差值，联合主体份额始终可以按成员拆回原登记主体。该试算不修改任何历史证据，响应固定声明不自动给出合法或违法结论，管理方需携带证据另行讨论。
